# Filter App

This is a simple React application that includes a filter component to demonstrate state management and component interaction.

## Project Structure

```
filter-app
├── src
│   ├── components
│   │   └── FilterField.tsx
│   ├── App.tsx
│   ├── main.tsx
│   └── styles.css
├── index.html
├── package.json
├── tsconfig.json
├── vite.config.ts
└── README.md
```

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd filter-app
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Run the application:**
   ```
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` (or the port specified in your terminal) to see the application in action.

## Usage

The application displays a title and includes a filter input field. You can type in the filter field to filter data as needed.
